このガイドラインは、[Livi の公式サンプル](../samples/v0.1.0/livi/livi.livf)とその内部素材に適用します。v0.1.0 のライセンスと追加許諾は、同じディレクトリの[外付けライセンス文書](../samples/v0.1.0/livi/livi.livf.license.txt)にも記載しています。サンプル全体の配置は [samples README](../samples/README.ja.md)を参照してください。

## Livi について

Livi は LIVF プロジェクトのマスコットキャラクターです。Livi を使った作品を、LIVF の利用者や創作者が自由に作り、公開できるようにしたいと考えています。

このガイドラインで守りたいのは、**Livi が LIVF から生まれたマスコットであるという出自**と、**どの作品が LIVF プロジェクトの公式発表かという区別**です。Livi の性格、設定、物語上の役割、表現方法を固定するものではありません。

## 利用できること

Livi の公式素材を使い、または Livi を題材にして、事前の許可なく次のことができます。

- イラスト、漫画、動画、ゲーム、配信、ウェブサイト、アプリ、教材、グッズなどに登場させる
- 表情、服装、姿、設定、性格、名前、世界観、他のキャラクターとの関係を変える
- 素材を抽出、加工、翻案し、別の形式へ変換する
- 元の素材や改変した作品を、無料・有料を問わず公開、配布、販売する

創作のジャンル、内容、制作手法について、このガイドライン独自の制限は設けません。LIVF 形式を使わない作品や、LIVF と直接関係しない作品にも Livi を登場させられます。LIVF プロジェクトによる内容の事前審査もありません。

Livi の公式サンプル `.livf` とその内部の素材には、原作者・権利者の Arashi Nawata が **Creative Commons 表示 4.0 国際（CC BY 4.0）**を適用し、無償・非商用の利用と技術・研究目的の利用には表示条件の免除を追加します。商用利用や改変も、事前の許可なく行えます。

Livi の素材やその改変物を公開・配布・公衆に表示する場合の扱いは、次のとおりです。「無償」と「非商用」の**両方**を満たす場合、または下記の技術・研究目的に該当する場合、権利者は CC BY 4.0 第 3 条(a)(1) の表示・通知条件を免除します。これは CC BY 4.0 の本文を変更するものではなく、権利者による追加の許諾です。

| 利用の形 | クレジットなどの表示 |
|---|---|
| 無償・非商用の作品や配布 | 不要。任意の表示は歓迎します |
| 技術・研究目的の利用 | 有償・商用でも不要 |
| 有料の創作作品・グッズへの利用 | 必要 |
| 無料でも広告収益を得る創作作品や、商品・サービスの販促への利用 | 必要 |

ここで「有料」とは、Livi を使った作品・サービス・グッズを受け取るために対価を支払う形を指します。「商用」とは、Livi の利用が主として商業上の利得や金銭的報酬を得ることに向けられている形を指します。利用者が企業か個人かだけでは判断しません。**技術・研究目的の免除に該当しない利用**で、有料または商用のどちらかに当てはまる場合は、CC BY 4.0 の通常の表示条件が適用されます。無償・非商用で公開した創作作品を本人や別の人が後から有料化・商用化する場合は、その公開・配布を始める時点で必要な表示を加えてください。

表示が必要な場合は、権利者が指定するクレジット、[ライセンスへのリンク](https://creativecommons.org/licenses/by/4.0/legalcode)、改変した場合はその旨などを、媒体に合った合理的な方法で示してください。ゲームのクレジット画面、配布ページ、同梱文書などにまとめて記載できます。個人的に閲覧・編集するだけの場合や、単に Livi の名前に言及する場合に表示は求めません。

表示例：

```text
Livi（LIVF マスコット）／原作: Arashi Nawata
CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
原素材: https://github.com/Karotte3500500/LIVF/blob/main/samples/v0.1.0/livi/livi.livf
```

上の表示は一例です。通常のライセンス条件は [CC BY 4.0 の原文](https://creativecommons.org/licenses/by/4.0/legalcode)に従います。無償・非商用利用と技術・研究目的の利用に対する表示条件の免除は、上記の追加許諾に従います。権利者が表示条件を免除できない第三者の素材は、Livi の公式素材に含めません。このガイドラインは、同ライセンスで認められた創作や利用に追加の制限を課すものではありません。

v0.1.0 の Livi `.livf` では、形式の仕様を維持するため、追加許諾を記した[ライセンス文書](../samples/v0.1.0/livi/livi.livf.license.txt)をファイル内には入れず、同じディレクトリに外付けで置きます。プロジェクトがサンプルを配布するときは、この文書も一緒に提供します。`.livf` だけが共有された場合にも追加許諾を確認できるよう、`manifest.json` の `metadata.license` にこの文書の公開 URL を記載します。v0.1.0 より後の形式バージョンでは、ライセンス文書を `.livf` 内に同梱する方式を仕様に定める方針です。

## 開発・研究・教育への利用

LIVF 形式の実装、検証、相互運用性の確認、テスト、ベンチマーク、研究、教育、技術文書や技術発表を**主な目的**として Livi の公式素材またはその改変物を利用する場合、有償・無償、商用・非商用を問わず、権利者は CC BY 4.0 第 3 条(a)(1) の表示・通知条件を免除します。

この免除には、パーサーやレンダラーのテスト、CI の fixture、公開リポジトリのテストデータ、SDK・ライブラリ・ツールに同梱するサンプル入力、形式変換の検証、機能紹介のデモ画面、論文・技術記事・発表資料中の画像を含みます。Livi がデモ画面に見えることや、ソフトウェアが有料であることだけを理由に、この免除の対象外にはしません。

一方、Livi を登場人物や鑑賞・販売の対象として用いるゲーム、動画、グッズなどの創作利用には、この技術・研究目的の免除を適用しません。技術紹介と創作利用の両方を行う場合は、創作利用に当たる公開・配布について通常の表示条件を確認してください。

## CC0 の汎用サンプル

LIVF 形式の基本的な確認に使える、Livi を含まない CC0 の `.livf` サンプルも用意する予定です。Livi は技術・研究目的であれば商用でも表示条件なしで利用できますが、用途による免除の判断を避けたい場合は、CC0 のサンプルを選べます。このサンプルはまだ公開されていません。

## 公式作品との区別

Livi を使った個人や団体の作品は、その制作者の作品です。LIVF プロジェクトが明示的に公式として公開したものだけを、LIVF の公式作品として扱います。

「Livi を使用した作品」「LIVF のマスコット Livi のファンアート」のように出自を説明できます。一方、自分の作品について「LIVF 公式」「LIVF 公認」など、プロジェクトが制作・承認・後援したと誤認させる表示は避けてください。LIVF の名称や公式ロゴを自分の製品・団体の公式な識別表示として使うことは、Livi の素材のライセンスとは別の問題です。

公式素材やこのガイドラインを利用しても、作品の内容について LIVF プロジェクトの承認や支持を受けたことにはなりません。
