# LIVF サンプル作品

**日本語** | [English](README.md)

Livi の v0.1 サンプルを収録しています。Livi を含まない CC0 サンプルは準備中です。

## 配置とバージョン

```text
samples/
├── README.ja.md
├── README.md
└── v0.1/
    ├── livi/
    │   ├── livi.livf
    │   └── livi.livf.license.txt
    └── cc0/
        ├── basic.livf                （予定）
        └── basic.livf.license.txt    （予定）
```

`v0.1/` は LIVF **ファイル形式**のバージョンを表し、配下のファイルの `manifest.json` にある `livfVersion: "0.1"` に対応します。実装やアプリのリリース番号ではありません。将来、別の形式バージョンのサンプルを追加する場合は、そのバージョンのディレクトリに分けます。サンプル素材は `.livf` ファイルだけを配置し、元画像などを個別の素材ファイルとして置きません。v0.1 では、例外として各 `.livf` に対応するライセンス文書を外付けで配置します。

## サンプルごとの利用条件

| 配置先 | 内容 | 利用条件 |
|---|---|---|
| `v0.1/livi/livi.livf` | LIVF のマスコット「Livi」を含むサンプル | **CC BY 4.0** と表示条件の追加免除。無償・非商用の利用はクレジット不要です。開発・研究・教育などを主な目的とする技術利用も、有償・商用を問わずクレジット不要です。その他の有償・商用の創作利用では表示が必要です。詳しくは [Livi のガイドライン](../docs/livi-guidelines.ja.md)と[外付けライセンス文書](v0.1/livi/livi.livf.license.txt)を参照してください。 |
| `v0.1/cc0/`（準備中） | Livi を含まない汎用サンプル | [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en) を適用予定です。用途を問わず、改変・再配布・商用利用ができ、クレジットは不要です。 |

Livi の条件は、`livi.livf` 内部の画像、サムネイル、`manifest.json` などにも適用します。Livi の利用条件を判断することに不安がある場合は、今後追加する `cc0/` のサンプルを選べます。

## ライセンス表示と権利確認

**v0.1 の暫定方式**として、各 `.livf` と同じディレクトリに、対応関係が分かる `<ファイル名>.license.txt` を置きます。[Livi の外付け文書](v0.1/livi/livi.livf.license.txt)には、CC BY 4.0 の表示条件についての追加免除も記載しています。プロジェクトがサンプルを配布するときは、対応する文書も一緒に提供します。`.livf` だけが共有された場合にも条件をたどれるよう、`manifest.json` の `metadata.license` には基本となるライセンスの識別子（Livi は `CC-BY-4.0`、将来の汎用サンプルは `CC0-1.0`）を記載します。Livi のファイルには追加免除を説明する外付け文書の公開 URL も記載しています。

**v0.1 より後の形式バージョン**では、ライセンス文書を `.livf` 内に同梱する方式を仕様に定める方針です。v0.1 の外付け方式は、その間の暫定的な運用です。

サンプルを追加する前に、ファイル内のすべての素材について、該当する条件で公開できる権利を確認します。Livi の v0.1 サンプルの画像と設定データは、原作者自身が作成したものです。CC0 サンプルに含める素材は、投稿者が CC0 で公開できる自作素材か、配布元と権利関係を確認した CC0 素材に限ります。投稿時には、自作・既存素材の内訳と、既存素材の配布元を記録します。

外付けの文書は、対応する `.livf` と内部素材の利用条件を示します。README や外付け文書そのものなど、`.livf` 以外のファイルには上記のサンプル用ライセンスを適用しません。ソースコードや仕様書などの条件は、リポジトリ直下の [LICENSE](../LICENSE)を参照してください。
